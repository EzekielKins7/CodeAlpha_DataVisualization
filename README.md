# CodeAlpha_DataVisualization

## 📌 Project Overview

This project is **Task 3 (Data Visualization)** of the **CodeAlpha Data Analytics Internship**. It demonstrates the transformation of raw data into meaningful visual formats like charts, graphs, and dashboards to reveal insights and support decision-making.

## 🚀 Features

- ✅ 7 different types of professional visualizations
- ✅ Bar charts, line charts, pie charts, scatter plots, heatmaps, box plots
- ✅ Combined dashboard view
- ✅ Interactive Plotly chart (HTML format)
- ✅ Business insights derived from visualizations
- ✅ Beginner-friendly, well-commented code

## 🛠️ Technologies Used

| Tool / Library | Purpose |
|---|---|
| Python 3.x | Core programming language |
| Pandas | Data manipulation |
| Matplotlib | Basic plotting |
| Seaborn | Statistical visualizations |
| Plotly | Interactive charts |
| NumPy | Numerical operations |
